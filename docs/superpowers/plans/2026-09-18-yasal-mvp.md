# Yasal MVP (Phase 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Yasal Phase 1 MVP — a blazing fast, ultra-lightweight (< 25 MB RAM idle, < 5 MB trimmed) Windows Command Palette built in Rust with `egui`/`eframe`, featuring global hotkey activation, app launcher with native icon caching, calculator, web search, shell execution, system commands, built-in settings, and Windows native theming with DWM Accent colors.

**Architecture:** Single-process Windows application with a background event loop managing system tray and global hotkey. The popup UI is rendered with `egui` and `window-vibrancy` (Acrylic/Mica blur). Plugin modules implement a unified `Plugin` trait routed via a query dispatcher with atomic search cancellation and frecency ranking. On window hide, memory is trimmed to < 5 MB via `EmptyWorkingSet`.

**Tech Stack:** Rust 2021, `eframe` / `egui` 0.29, `window-vibrancy` 0.5, `global-hotkey` 0.6, `tray-icon` 0.19, `windows` 0.58 (Win32 APIs: DWM, Shell, COM, ProcessStatus), `nucleo-matcher` 0.3, `evalexpr` 11.3, `open` 5.0, `dirs` 5.0, `serde` / `serde_json` 1.0.

## Global Constraints

- **Language & Edition:** Rust 2021 Edition.
- **Platform:** Windows 10 (1809+) and Windows 11 (x86_64).
- **RAM Target:** < 25 MB active idle, < 5 MB after `EmptyWorkingSet` memory trim on window hide.
- **Latency Target:** < 50 ms hotkey to visible, < 30 ms keystroke to search results.
- **UI Layout:** Fixed 40px row height, 24×24px cached native icons, max 8 visible items (virtualized), 650×420px window centered on primary display.
- **Interaction Rules:** In-place Action Panel on `Tab`, 2-step `Esc` (clear text -> close window), dynamic contextual status bar hints, native Windows dialogs for destructive confirmations.
- **Theming:** Real-time Windows Dark/Light mode detection + DWM Accent Color synchronization, with manual override option in Settings (`Auto/Dark/Light`).

- [ ] **Step 2: Implement src/platform/win32.rs with EmptyWorkingSet, DWM accent query, and MessageBoxW**

```rust
use windows::Win32::System::ProcessStatus::EmptyWorkingSet;
use windows::Win32::System::Threading::GetCurrentProcess;
use windows::Win32::Graphics::Dwm::{DwmGetColorizationColor, DWMWA_USE_IMMERSIVE_DARK_MODE};
use windows::Win32::UI::WindowsAndMessaging::{MessageBoxW, MB_OKCANCEL, MB_ICONWARNING, IDOK};
use windows::core::HSTRING;

pub fn trim_memory() {
    unsafe {
        let _ = EmptyWorkingSet(GetCurrentProcess());
    }
}

pub fn get_system_accent_color() -> (u8, u8, u8) {
    let mut colorization: u32 = 0;
    let mut opaque: windows::Win32::Foundation::BOOL = Default::default();
    unsafe {
        if DwmGetColorizationColor(&mut colorization, &mut opaque).is_ok() {
            let r = ((colorization >> 16) & 0xFF) as u8;
            let g = ((colorization >> 8) & 0xFF) as u8;
            let b = (colorization & 0xFF) as u8;
            return (r, g, b);
        }
    }
    (0, 120, 215) // Windows default blue fallback
}

pub fn is_system_dark_mode() -> bool {
    // Query registry for AppsUseLightTheme
    use windows::Win32::System::Registry::{RegOpenKeyExW, RegQueryValueExW, HKEY_CURRENT_USER, KEY_READ, REG_DWORD};
    let subkey = HSTRING::from("Software\\Microsoft\\Windows\\CurrentVersion\\Themes\\Personalize");
    let value_name = HSTRING::from("AppsUseLightTheme");
    let mut hkey = Default::default();
    unsafe {
        if RegOpenKeyExW(HKEY_CURRENT_USER, &subkey, 0, KEY_READ, &mut hkey).is_ok() {
            let mut data: u32 = 0;
            let mut data_len = std::mem::size_of::<u32>() as u32;
            let mut reg_type = REG_DWORD;
            let res = RegQueryValueExW(hkey, &value_name, None, Some(&mut reg_type), Some(&mut data as *mut u32 as *mut u8), Some(&mut data_len));
            if res.is_ok() {
                return data == 0;
            }
        }
    }
    true // Dark mode fallback
}

pub fn show_confirm_dialog(title: &str, message: &str) -> bool {
    let title_w = HSTRING::from(title);
    let msg_w = HSTRING::from(message);
    unsafe {
        let res = MessageBoxW(None, &msg_w, &title_w, MB_OKCANCEL | MB_ICONWARNING);
        res == IDOK
    }
}
```

```rust
use global_hotkey::{GlobalHotKeyManager, hotkey::{HotKey, Modifiers, Code}, GlobalHotKeyEvent};

pub struct HotkeyManager {
    manager: GlobalHotKeyManager,
    hotkey: HotKey,
}

impl HotkeyManager {
    pub fn new_alt_space() -> Result<Self, Box<dyn std::error::Error>> {
        let manager = GlobalHotKeyManager::new()?;
        let hotkey = HotKey::new(Some(Modifiers::ALT), Code::Space);
        manager.register(hotkey)?;
        Ok(Self { manager, hotkey })
    }

    pub fn is_triggered(&self) -> bool {
        if let Ok(event) = GlobalHotKeyEvent::receiver().try_recv() {
            return event.id == self.hotkey.id() && event.state == global_hotkey::HotKeyState::Pressed;
        }
        false
    }
}
```

```rust
use tray_icon::{TrayIcon, TrayIconBuilder, menu::{Menu, MenuItem, MenuEvent}};

pub enum TrayEventAction {
    ToggleWindow,
    OpenSettings,
    Quit,
}

pub struct TrayManager {
    _tray_icon: TrayIcon,
    show_item: MenuItem,
    settings_item: MenuItem,
    quit_item: MenuItem,
}

impl TrayManager {
    pub fn new() -> Result<Self, Box<dyn std::error::Error>> {
        let menu = Menu::new();
        let show_item = MenuItem::new("Show Yasal (Alt+Space)", true, None);
        let settings_item = MenuItem::new("Settings", true, None);
        let quit_item = MenuItem::new("Exit", true, None);
        menu.append_items(&[&show_item, &settings_item, &quit_item])?;

        let tray_icon = TrayIconBuilder::new()
            .with_menu(Box::new(menu))
            .with_tooltip("Yasal Command Palette")
            .build()?;

        Ok(Self { _tray_icon: tray_icon, show_item, settings_item, quit_item })
    }

    pub fn poll_action(&self) -> Option<TrayEventAction> {
        if let Ok(event) = MenuEvent::receiver().try_recv() {
            if event.id == self.show_item.id() {
                return Some(TrayEventAction::ToggleWindow);
            } else if event.id == self.settings_item.id() {
                return Some(TrayEventAction::OpenSettings);
            } else if event.id == self.quit_item.id() {
                return Some(TrayEventAction::Quit);
            }
        }
        None
    }
}
```

```rust
use nucleo_matcher::{Config, Matcher as NucleoMatcher, Utf32Str};

pub struct Matcher {
    config: Config,
}

impl Matcher {
    pub fn new() -> Self {
        Self { config: Config::DEFAULT }
    }

    pub fn fuzzy_score(&self, pattern: &str, text: &str) -> Option<u32> {
        let mut matcher = NucleoMatcher::default();
        let mut pattern_buf = Vec::new();
        let mut text_buf = Vec::new();
        let pattern_utf32 = Utf32Str::new(pattern, &mut pattern_buf);
        let text_utf32 = Utf32Str::new(text, &mut text_buf);
        
        let score = matcher.fuzzy_match(text_utf32, pattern_utf32, &self.config);
        score.map(|s| s as u32)
    }
}
```

`src/core/dispatcher.rs`:
```rust
use crate::core::plugin::{Plugin, QueryResult};
use std::sync::Arc;

pub struct Dispatcher {
    plugins: Vec<Arc<dyn Plugin>>,
}

impl Dispatcher {
    pub fn new() -> Self {
        Self { plugins: Vec::new() }
    }

    pub fn register(&mut self, plugin: Arc<dyn Plugin>) {
        self.plugins.push(plugin);
    }

    pub fn dispatch(&self, query: &str) -> Vec<QueryResult> {
        let trimmed = query.trim();
        if trimmed.is_empty() {
            return Vec::new();
        }

        // Check prefix match
        for plugin in &self.plugins {
            if let Some(prefix) = plugin.prefix() {
                if trimmed.starts_with(prefix) {
                    let rest = trimmed[prefix.len()..].trim();
                    return plugin.query(rest);
                }
            }
        }

        // Global broadcast
        let mut results = Vec::new();
        for plugin in &self.plugins {
            if plugin.is_global() {
                results.extend(plugin.query(trimmed));
            }
        }
        results.sort_by(|a, b| b.score.cmp(&a.score));
        results.truncate(8); // Max 8 items
        results
    }
}
```

```rust
use std::path::{Path, PathBuf};
use std::fs;

pub struct IconCache {
    cache_dir: PathBuf,
}

impl IconCache {
    pub fn new() -> Self {
        let local_app_data = dirs::data_local_dir().unwrap_or_else(|| PathBuf::from("."));
        let cache_dir = local_app_data.join("Yasal").join("IconCache");
        let _ = fs::create_dir_all(&cache_dir);
        Self { cache_dir }
    }

    pub fn get_icon_path(&self, app_identifier: &str) -> PathBuf {
        let hash = format!("{:x}", md5_or_simple_hash(app_identifier));
        self.cache_dir.join(format!("{}.png", hash))
    }
}

fn md5_or_simple_hash(input: &str) -> u64 {
    use std::collections::hash_map::DefaultHasher;
    use std::hash::{Hash, Hasher};
    let mut hasher = DefaultHasher::new();
    input.hash(&mut hasher);
    hasher.finish()
}
```
